Rules the user has taught, or that the work has shown. Instructions to
the tosla-strategist agent. One dated line each. Newest rules win.

## How the user likes to work
- 2026-10-06: Ask clarifying questions before giving details when a request is ambiguous; otherwise state the assumption and proceed.
- 2026-10-06: Keep replies short: file path plus summary; details live in the reports.
- 2026-10-06: When the user hands over a revised agent file, merge it with earlier instructions (category focus, no Revuze, Spate, memory) rather than overwriting them, and say what was kept.

## Scope and sources
- 2026-10-06: Category focus is supplements, wellness and nutricosmetics; markets US, EU and UK unless told otherwise.
- 2026-10-06: Never use Revuze unless the user explicitly asks.
- 2026-10-06: The user adds Spate exports on request; always say which Spate searches would help and where to put them (inputs/<slug>/ or inputs/category/).
- 2026-10-06: Use Firecrawl for web research and to find hard-to-find documents (PDFs, filings, decks); read original pages before citing figures.
- 2026-10-06: Claude Projects, NotebookLM and SharePoint cannot be reached from here; ask the user to upload files or paste key points instead.

## Approaching brands

- 2026-10-06: Only claim TOSLA capabilities written in inputs/tosla/profile.md; no client brand names are public, so never imply named references.
